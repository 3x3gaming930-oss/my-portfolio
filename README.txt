PERSONAL PORTFOLIO WEBSITE
==========================

FILES
- index.html : website content and structure
- style.css  : layout, responsive design, colors, and effects
- script.js  : mobile menu, theme switch, back-to-top button, and year

NOTE
The contact button opens the visitor's email app using mailto. It does not store or send messages through a server.
The project cards are sample placeholders, not live applications.
